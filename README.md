# notepad#

A simple notepad app written in C#, free of AI features and Microsoft integration. 

## Features
- Write plain text
- Save .txt files
- Open .txt files
- Find
- Zoom in/out
- Choose font
- Prints (now with ALL pages!)

## Non-features
- Does not format text
- Does not spell check
- Does not connect to the internet
- Does not have Copilot functionality
- Does not have a remote code execution vulnerability

## Building
``` dotnet build```

Alternatively, download the .exe from the 'Releases' to the right.
